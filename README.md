# 🌍 蓝色星球 BluePlanet — 地球地理知识科普

> 🌐 **在线体验：https://leon1734.github.io/blue-planet/** · 仓库：https://github.com/Leon1734/blue-planet · 也可双击 index.html 离线玩

零依赖、零构建的可交互 3D 地球科普页面。双击 `index.html` 即可运行（无需服务器、无需联网）。

## 数据扩充指南

所有内容集中在 `js/data.js`，组件零硬编码：

- **新增知识点**：向 `BP_POIS` 追加 `{ id, module, title, lat, lon, difficulty(1-3), tags, summary, content[段落数组], kind?(mountain/volcano/ocean/river/climate/geo/ice/human) }`，光柱、拾取、卡片、导航计数自动生成
- **新增模块**：向 `BP_MODULES` 追加 `{ id, name, color, desc, cam:{lat,lon,dist} }`，导航与过滤自动生效
- **新增地名标注**：向 `BP_LABELS` 追加 `{ t, lat, lon, k, z(1远/2中/3近) }`
- **换贴图**：替换 `textures/` 下同名文件后执行 `node tools/gen-textures.js`（earth_topo.jpg 为全球高程图，陆地灰度=海拔、海洋为 0，shader 依此做地形浮雕）
- **改版必递增** `index.html` 中的 `?v=` 缓存号（当前 `bp15`，与 `sw.js` 的 CACHE 版本一起升）

## 技术要点

- 晨昏线：太阳方向由 UTC 时刻计算（含太阳赤纬 + 均时差），昼/夜贴图在 fragment shader 中按 `smoothstep` 混合，误差 < 1° 经度
- 相机飞行：球面坐标插值（经度取最短弧 + easeInOutCubic），不会穿越地球
- 性能：pixelRatio 上限 1.75 + 帧时间 EMA 自动降质；页面隐藏自动停 rAF（省电，内嵌 WebView 友好）
- file:// 兼容：贴图内嵌、无 fetch、无 ES module import，传统 script 全局命名空间（`BP*` 前缀）

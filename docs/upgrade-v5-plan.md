## 一、地理小助手接入免费大模型（需求②）

### 1.1 服务商设置面板
- 助手头部新增 ⚙️ 按钮 → 设置区：**服务商下拉**（智谱 GLM-4-Flash / 硅基流动 / 自定义 OpenAI 兼容端点）+ **API Key 输入**（密码框）+ **模型名**（预填默认）+ 保存。
- Key 仅存本机 localStorage（`bp_llm_v1`），明文不进代码、不进 git。
- 连通性测试按钮：保存时发一条 1 token 测试消息，成功/失败即时反馈。

### 1.2 请求与降级链
- 统一走 OpenAI 兼容 `POST /chat/completions`，`stream: true` SSE 流式 → 接入现有打字机（逐段追加，替代逐字定时器）。
- 系统提示词：「你是蓝色星球科普页的地理助手，面向中文青少年，回答简洁准确，不超过 200 字」+ 动态上下文（当前选中知识点的标题与摘要）。
- **降级链**：外部 API 报错/超时（8s）→ 自动回落本地 26 条规则库，并 toast 说明原因（未填 Key / Key 无效 / 网络失败）。
- 界面标示：回答气泡角标区分 🤖本地 / ✨GLM-4-Flash 等，来源一目了然。

### 1.3 免费获取指引（内置在设置面板的说明文字里）
- 智谱：open.bigmodel.cn 注册 → API Keys → 创建即可调用 glm-4-flash（免费）。
- 硅基流动：cloud.siliconflow.cn 注册送额度，免费模型 Qwen/Qwen2.5-7B-Instruct 等。

## 二、你知道吗 → 「今日地球」（需求①：解决内容重叠）

**分工重定义**：光柱卡片 = 深度阅读（点开才有）；今日地球 = 每日仪式感（日期驱动，不再是与模块内容同质化的常驻小知识）。

- factCard 改版为「📅 今日地球」：
  1. **日期头**：当日日期 + 星期。
  2. **今日地理纪念日**：新增 `BP_CALENDAR`（~60 条，按「月-日」匹配）：如 4·22 世界地球日、3·23 世界气象日、6·5 环境日、12·25 旅行者 1 号…；无匹配日则显示当月主题知识（如"本月聚焦：极地"）。
  3. **今日推荐**：保留现有 dailyPoi 大按钮（随机抽中当日推荐时的彩蛋 toast 保留）。
  4. **冷知识**改为手动「换一条」按钮 + 点击冷知识可跳转关联知识点（给 BP_FACTS 加可选 `poi` 字段，先给重点 12 条配链接）。
- 自动轮播取消（减少与光柱内容的"同时竞争"），位置/样式沿用现有 factCard。
- 移动端今日地球收成一行芯片，点开展开。

## 三、知识点卡片图文并茂（需求③）

### 3.1 类型化 SVG 图解（离线恒定的"图"）
- 新文件 `js/figures.js`：8 类手绘风 SVG 图解生成器（按 POI kind 自动匹配，模块色着色）：
  - mountain 山峰剖面（等高线+雪线）｜ volcano 火山结构（岩浆房/通道/火山灰柱）｜ ocean 海洋深度带（海沟/大陆架）｜ river 河流水系（干支流+河口）｜ climate 大气环流示意 ｜ ice 冰川极地（冰盖剖面）｜ human 工程剪影 ｜ geo 地球圈层剖面
- 图解置于卡片标题下方，固定 3:2 比例，浅色底融入深空主题。

### 3.2 数据速览条（"文"的结构化）
- `BP_POIS` 新增可选 `stats` 字段：`[{k:'海拔', v:'8848.86 m'}, {k:'年抬升', v:'~4 mm'}]`。
- 卡片渲染为图标化速览 chips（黄金速览区，先给 30 个代表 POI 补齐，其余显示图解+正文缺省）。

### 3.3 图片扩展位
- `BP_POIS` 新增可选 `img` 字段（data URI 或 http URL）：有则优先显示真实图片；本期先接管线、不放图，后续可零代码补图。

### 3.4 排版
- 卡片结构改为：模块章 + 标题/难度 → **图解/图片** → **速览条** → 摘要 → 正文 → 标签 → 页脚（坐标+同模块下一个）。

## 五、风险与对策

- **免费 API 限流/失效**：多 provider 可切换 + 本地规则永久兜底；超时 8s 即降级不卡 UI。
- **Key 安全**：只存 localStorage、只在浏览器直连官方端点、文档明示"自用勿分享 Key"。
- **SVG 图解工作量**：8 类通用图解覆盖 77 卡，不做 77 张定制图；后续按需补 `img`。
- **日历准确性**：纪念日采用联合国/我国官方日期，写作时逐条核对。
